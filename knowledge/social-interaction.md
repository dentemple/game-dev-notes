# Social Interaction (Dialogue, Morality, Reputation)

## Goal & scope

Two influential models of story-relevant social interaction — BioWare's cinematic **dialogue wheel +
morality** (Mass Effect) and Bethesda/Obsidian's **text tree + skill checks + faction reputation**
(Fallout) — distilled into transferable patterns. Companion to narrative-storytelling.md and
features/quest-dialogue.md.

## Primary sources

- **rpgcodex — Avellone on New Vegas**: https://rpgcodex.net/article.php?id=7142 (accessed 2026-11-18)
- **Mass Effect / Fallout design analyses** (RESEARCH, search summaries) (accessed 2026-11-18)

## The two models (RESEARCH unless labeled)

### Mass Effect — the dialogue wheel + Paragon/Renegade
A **cinematic conversation wheel** that shows *tone* (not full text), with a binary **Paragon/Renegade**
axis (order-vs-chaos, inherited from KOTOR); high scores in either axis unlock special options [C1]. The
critique that led to its retirement: it pushed players to "stick to one path" (players would "hit Paragon
every time"), so Andromeda replaced it with **four personality tones** (logical/passionate/casual/
professional) — expressive, but less consequential [C2]. Choice/consequence was carried via **save import**
and **companion loyalty/romance** modeled as per-companion boolean flags (not a global meter); the ME2
suicide-mission deaths produced "regret states" later [C3].

### Fallout — the text tree + skill checks + faction reputation
New Vegas loaded dialogue with **skill checks** ("There's a lot of skill checks in conversations") and
**faction checks** ("checks for faction, and different reactions depending on rep") [C4]. Reputation is
**two-axis**: Fame and Infamy (1-4) tracked *separately*, so good and bad deeds toward a faction don't
cancel — producing nuanced labels like "Soft-Hearted Devil" and "Dark Hero" [C5]. Sawyer's rule: each
skill-gated option has **two text versions** (success/failure), and non-Speech skills (Science, Explosives,
Medicine) get real dialogue relevance [C6]. Avellone's rule: **non-violent/speech paths must reward
comparably** to killing/looting, so talking your way out isn't a penalty [C7]. Fallout 3's single-axis
**karma** (a "universal" good/evil meter) is the contrast — New Vegas demoted it in favor of per-faction
reputation + branching endings (NCR/Legion/House/Yes Man) [C8].

## Transferable patterns (ANALYSIS)

1. **Wheel vs. tree**: use the *wheel* for cinematic tonal expression (few, legible intents); use the *tree*
   for information-rich, skill-gated roleplay.
2. **Reputation over morality**: track **per-faction/relationship standing** (two axes, non-cancelling)
   rather than one global good/evil meter — it's more nuanced and more legible.
3. **Skill-gate dialogue** to express character build (Science/Speech/Explosives), with distinct
   success/failure text.
4. **Make choices legible and consequential** — the player should see the fork *and* later feel its
   consequence (ME's save import, New Vegas's ending slides).
5. **Reward talk as much as fight** — a speech "win" should be as valuable as a combat win.

## Anti-patterns / gotchas

- A single binary morality axis (Paragon/Renegade, F3 karma) — reductive, pushes one-path play [C2][C8].
- Skill-gated options that are "auto-win" buttons with the requirement displayed (enables save-scumming).
- Branching choices that reconverge to the same outcome (hollow consequence).
- A wheel that hides what the character will actually say (the "surprise line" problem).
