# Encounter Design (5 Room Dungeon & Pacing)

## Goal & scope

How to structure encounters/dungeons for pacing and variety — the **5 Room Dungeon** pattern plus the
encounter-building principles (terrain, action economy, telegraphing). Companion to combat.md.

## Primary sources

- **Tribality** — Johnn Four's "5 Room Dungeon":
  https://www.tribality.com/2016/04/15/5-room-dungeons-filling-your-dungeon-with-interesting-stuff/ (accessed 2026-11-18)
- **Encounter consensus** — action economy, terrain, telegraphing (RESEARCH, synthesized from the combat/enemy feature files; accessed 2026-11-18)

## Key decisions / trade-offs

- **Five scenes, not five rooms** — a pacing skeleton, not a literal layout; each beat exercises a
  different player skill (combat, problem-solving, resource management).

## Implementation notes (sourced unless labeled)

- **The 5 Room Dungeon** (Tribality): "a pattern to quickly and easily build a dungeon crawl or any short
  adventure with 5 locations" —
  1. **Entrance with Guardian** (why it isn't already plundered),
  2. **Puzzle or Roleplaying Challenge** (non-combat, spotlights different skills),
  3. **Trick or Setback** (a twist/loss that raises the stakes),
  4. **Big Climax** (the set-piece battle),
  5. **Reward, Revelation** (payoff + hook to the next adventure).
  Reorder/expand freely (3-10 areas); it works for any location type.
- **Action economy is the real balance lever** (RESEARCH) — a fight is hard when the enemy side gets more
  effective actions; add minions or waves rather than only inflating HP. (see combat-dnd5e.md)
- **Terrain is a participant** (RESEARCH): height, cover, chokepoints, hazards (see combat-dnd5e.md
  for BG3's high-ground and surface systems).
- **Pace by waves/turns** (RESEARCH): escalate intensity; give the player a "read" (telegraph) before
  each new threat (see combat-windwaker.md).
- **Each encounter should test something different** (RESEARCH) — don't chain identical slugfests (see
  enemy-tactics.md).

## Anti-patterns / gotchas

- Literal "five rooms" thinking instead of five *beats*.
- Difficulty via HP inflation only (ignores action economy).
- Flat, featureless arenas with no terrain/cover/hazards.

## Verify-first

Re-verify the 5 Room Dungeon beats against roleplayingtips.com (Johnn Four's source) before treating
them as canon for your own levels.
