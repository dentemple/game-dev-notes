# Product Development Lifecycle

## Phases (practitioner consensus)

Concept → Pre-production → Production → Testing/QA → Launch → Post-launch / live ops.

## Three de-risking artifacts (primary definitions)

- **Prototype** — proves the core mechanic is fun; rough, internal.
- **Vertical slice** — "a fully playable portion of a game that shows the developer's intended player experience" with "assets representing the final quality." "Final quality assets distinguish the vertical slice from earlier game iterations like an initial playable build, a functioning prototype, or a minimum viable product (MVP)."
- **MVP** — smallest playable version worth testing with players; functional, not polished.
Source: https://xsolla.com/blog/funding-101-the-impact-of-the-vertical-slice (accessed 2026-11-18).

## Milestone gates (practitioner)

- **Alpha** = feature-complete; **Beta** = content-complete; then launch candidate, then live ops.
- De-risking order for a solo dev: "core loop first, then the vertical slice, then content breadth, then polish."
Source: https://bugnet.io/blog/project-management-for-solo-game-devs (accessed 2026-11-18).

## Key trade-off

The cost of being wrong compounds with each phase. Validate fun (prototype) and vision (vertical slice) before mass-producing content; skipping pre-production is the most common cause of scope creep and overrun.
